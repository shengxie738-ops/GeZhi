# 学生 Git 教练：当前任务证据隔离

日期：2026-10-05

## 本次结果

当前任务的状态改为依据明确的任务版本和来源证据计算。前一任务的 push、PR 或合并记录，不能直接让重新分配的任务显示完成。

- 实际变更任务、分支或仓库身份时，建立新的任务版本，归档旧任务证据并重置当前工作流；重复相同的已建立分配保持幂等
- PR 绑定要求稳定成员身份、实际提供的同仓库 head/base 身份与不可变仓库 ID、精确任务分支和默认目标分支，以及不早于分配边界的可靠创建时间
- 已建立的本地任务绑定和首次观察版本保留；复用旧任务分支、缺少身份或时间、旧任务版本及演示记录保持未验证
- 已充分观察到的本任务 PR 合并，不会被后续过时的 open 快照或缺少字段的快照覆盖；这些后续原始记录仍保留在历史中，不补造缺失身份
- 同步中的新增规范化观察与历史会与最新任务分配重新合并；旧版本证据仍可查看，不能升级新任务进度
- 保留历史任务、PR、提交证据和累计贡献计数；当前任务完成数量和提醒使用当前任务投影
- 只有学生明确确认拉取的操作记录才能提供“本人确认已拉取”证据；远端提交不能证明本机 clone
- 当前适配器没有足够的 push 发生时间来自动建立可靠任务绑定。提交列表、刷新成功和 PR 存在均不会补造“已检测到本任务 push”

合并状态使用“本任务 PR 已合并”。它只描述对应任务的远端 PR 工作流，不证明代码正确、测试通过、原生审核通过、学生掌握程度或本机合并后同步。

## 验证范围

40 个离线检查全部通过：生产纯函数的合成输入行为测试，以及服务和适配器源码的 AST 接线检查。检查覆盖重新分配、身份与时间不匹配、旧版本、分支复用、重复与顺序、快照缺席、过时及不完整快照、历史保留和最新任务证据合并。

服务、回调及适配器没有在这些检查中执行。没有据此验证真实 Gitea 字段是否提供、回调认证与投递、数据库持久化、事务并发序列化、真实远端合并、CI、本机 Git 行为或浏览器界面。项目仍只面向电脑端页面；本次没有进行浏览器或移动端验收。

现有权限检查、JSON 存储、外部操作通路和学习系统初审与原生审核的来源区分保留。没有新增数据库结构、通用工作流引擎或原生审核写入。

## 后续界面与指导工作

前端工作流卡片和安全操作指导仍待下一步完成，本次不能视为完整 Git 教练界面已验收。

未验证的 push 不应锁死学生的合理手动 PR 操作：在仓库地址和任务分支已明确时，保留手动创建 PR 的链接，并明确提示本机分支、实际推送和工作区检查前提；状态仍须保持未知，不能据此标记已 push。

下一步还需使用当前任务投影呈现卡片和提示，区分审核、远端合并与本机同步，并替换不安全或缺少前提的命令示例。
