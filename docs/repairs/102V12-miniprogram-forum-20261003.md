# 102V12：小程序论坛与会话交互修复

日期：2026-10-03

接续 Web 论坛检查点 `d002a9b`，本阶段仅修改小程序论坛详情页、普通请求的会话保护，以及两份对应测试。

## 修复内容

- 点赞调用真实后端并采用已确认计数，不再修改本地缓存冒充成功，也不模拟后端未提供的取消点赞
- 回复仅发送正文；权限来自当前会话的服务端上下文和帖子权限，历史昵称或 isAi 字段不能形成教师/官方审核身份
- 读取失败、帖子缺失、未登录、权限不足和提交未确认均明确显示，不使用空白默认帖子或成功提示掩盖问题
- 保护切换账号、切换帖子、离开页面和提交期间继续编辑的场景；旧响应不会更新新状态或清空新草稿
- 已确认回复/点赞不会被较早启动的读取覆盖；相同服务端 ID 不重复插入
- 旧会话的成功、401 或网络失败不能清除或导航新的会话；普通请求仍保留既有代理参数及两类响应封装
- 如果点击或输入首先发现登录令牌变化，会启动一次新会话读取，而不是停在无法操作的空闲页面；不会自动重放旧操作

上传函数及其后续辅助函数、配置、云函数、样式、后端和 Web 论坛均未修改。
