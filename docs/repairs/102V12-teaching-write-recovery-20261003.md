## 本次变化

- 专用会话在身份查询前配置 READ COMMITTED，由 HTTP 适配器负责提交成功后再返回成功响应；服务层不自行提交，会话退出时清理剩余事务
- 声明并按序处理课程、开课、账号、关系、预览与既有回执的锁范围，再读取同代策略和最终数据库时间进行当前授权判断
- 原始回执保留接受时的结果；同一请求重放不会用后续版本覆盖历史结果。恢复仍要求原操作者具备当前权限，回执不能作为长期授权凭据
- 业务变化、单份原始回执和单条访问事件使用同一事务。写入失败或提交结果不确定时，响应保留原始 action、scope_type、scope_id、key 恢复引用，不附带请求正文、凭据或哈希，也不自动更换请求键
- 补充锁范围收集阶段的只读约束、事务连续性检查及返回和提交前的干净状态检查。新的写入和回执重放均保留防御性边界
- 新增独立的回执恢复适配器、严格查询和响应字段及 no-store 响应；尚未接入主应用路由，也未实现后续课程、名册或角色写入功能
