# Desktop teaching shell checkpoint

Adds a read-only desktop teaching workbench with course/offering discovery, explicit local teaching/learning modes, truthful resource states, and guarded navigation back to existing tools. Existing public course preview controls remain; their copy distinguishes preview from unsupported persistence.

Authentication and teaching-entry state prevent eager legacy dashboard requests. Learning-mode selection reloads current own enrollment through the existing fenced reader. The keyboard skip control moves focus without changing the route. Exam navigation uses the actual answer-flush contract.

Seven separately selected guarded synthetic scopes passed against the final frozen source: workbench 34, teaching context 39, teaching navigation 21, legacy navigation 2, authentication transition 3, API contracts 27, and capabilities 8. Independent source/evidence review accepted the exact 15-path application candidate after corrections. This is scoped compiler/SSR/Vue lifecycle and source-wiring evidence, not a whole-repository pass.

Rendered desktop visual, keyboard, focus, scrolling, native select and menu behavior require separate browser QA. No mobile or tablet work is in scope. Foreground-return revalidation is not yet wired; current authentication entry, explicit refresh and guarded navigation are the implemented revalidation paths.

Assignment and submission views are explicitly marked not connected in this shell. It does not complete the assignment workflow or enable business mutations. Real database migration/locking acceptance and production activation remain separate gates. Backend write safety and frontend mutation availability remain closed. No main merge or deployment is included.
