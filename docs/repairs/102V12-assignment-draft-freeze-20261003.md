# GeZhi 作业草稿与版本冻结服务进展

本阶段已完成作业草稿、私有答案、版本冻结及教师按当前权限重新查询作业的后端服务实现，并通过限定范围的源码与合成数据验证。HTTP 端点和前端界面尚未接入，生产写入仍保持关闭。

## 已实现的服务

- 创建作业时建立公开草稿与独立的空私有草稿。公开内容和私有答案可分别完整替换，共用草稿修订号；保存时检查预期修订，避免覆盖较新的内容
- 冻结操作复制已锁定的公开与私有快照，生成不可变版本。后续编辑保留旧版本；同一修订不能再次冻结。作者显式再次保存相同公开内容后，可产生新修订并冻结新版本
- 公开内容摘要只计算公开快照。私有答案和私有摘要留在独立私有存储中，不进入公开查询结果、写入回执或事件记录。文本按原样保存，不执行其中的代码或测试说明
- 有创作权限的教师可查询可变草稿目录；仅有发布权限的教师只能看到已有冻结版本的作业，目录标题与时间取自最新冻结公开版本。版本列表按版本号升序返回，每次目录、详情和私有内容查询都重新检查当前账户、角色、可信权限范围与对象关系
- 私有内容需要独立权限。教师兼任学习者时，当前选课关系限制私有草稿访问；某冻结版本的接收者不能读取该版本的私有答案。已接受写入的重试保留原回执，当前权限失效仍会拒绝访问

## 分页约束

新增纯分页游标处理，仅支持作者草稿目录、发布者冻结目录、作业版本列表三种类型。游标绑定当前账户、查询对象及目录投影，严格检查字段、位置范围、编码、UTF-8 与大小上限，拒绝重复或未知字段及错误绑定。

游标只是客户端提交的不可信位置，不提供访问授权；翻页仍需重新检查当前权限。

## 尚未开放的能力与验证限制

生产写入安全门保持原样，仍无条件返回 503 write_safety_unproven；教学功能默认开关未改变。本阶段没有启用、部署或迁移数据库，也没有接入 HTTP 流程、前端作业编辑器或真实浏览器操作。

真实 MySQL 的迁移与物理约束、并发锁顺序、最终时钟后的外键及唯一键等待、提交结果不确定时的恢复等验证仍未执行。既有 B1 真实 MySQL 验证要求和 B2 运行前提继续保留。源码与合成测试通过不代表已具备生产写入安全性或线上可用性。

本阶段不包含作业发布与提交服务接入、自动评测、评分、代码执行或历史作业数据回填。
