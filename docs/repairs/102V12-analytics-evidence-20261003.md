# 102V12：学情记录与证据口径修复

日期：2026-10-03

本阶段接续 `61fc4a9` 检查点，仅修改学情接口、教师学情中心、教师仪表盘的行动记录消费，以及对应配置声明和两份测试。

## 修复内容

- 保留有用的已保存提交类记录、错题记录、论坛记录和交互完成记录计数，明确标注保存事实、历史来源未核验或账号自报完成
- 当前规范账号和教师分配名单仍是权限与分母依据；记录所有者取自持久化元数据，昵称、客户端账号字段或自称已核验标记不能授予身份与权威
- 周统计使用最近七个完整 UTC 日，按记录首次保存时间计算每日不同账号比例；小时统计使用同一窗口内各 UTC 小时的不同账号数，排除窗口外和未来记录
- `ANALYTICS_RECORDED_TIMEZONE` 默认空。部署者独立确认所有相关历史记录采用一致的存储时间约定后，才可声明 UTC 或受限固定偏移；宿主时区、当前 MySQL 会话和前端参数不能证明历史约定。未知或混用时保持空值，朴素时间的日期/小时分布不可用，已知保存总数仍保留
- 未建立的进度、专注、风险、在线状态、班级评价和完成口径保持未知；真实数值零与未知值分开处理。等级成绩、原始分数和诊断推断分别展示，不制造百分数、混合能力分或默认曲线
- 部分缺失的雷达数据展示逐项证据，折线保留未知间隙。总览读取失败时，已成功读取的个人证据仍可展示；选择变化后，旧响应不会覆盖新学生或恢复已清除的数据
- 历史建议与行动统一标注“历史记录；依据未核验”，保留服务端接收账号。手动交互须取得保存记录 ID 才显示保存回执；不据此确认实际送达、已读或学习完成
- 查看总览不再自动保存建议或行动。排期、自动生成和缺少回执支持的提醒操作显示不可用，不伪造成功、减少未读数或提升学生指标
- 无效的嵌套论坛回复 ID 不会中断规范名单读取；错题 JSON 无法解析时，仍保留成功读取的确切保存行数，并区分可用事实覆盖范围
- 交互来源读取失败或未读计数缺失、为空或格式错误时显示不可用；完整空列表和真实数值零仍准确保留

## 接口兼容性变化

以下两个现有自动生成接口暂时返回 HTTP 503，错误详情为 `analytics_generation_unavailable`：

- `POST /analytics/advices/generate`
- `POST /analytics/action-queue/generate`

调用方需要明确处理不可用状态。历史保存记录仍可按原权限读取，现有手动交互功能保留；本阶段未修改其他 AI 功能或模型配置。
