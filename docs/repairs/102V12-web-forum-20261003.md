# 102V12：Web 论坛接口与交互修复

日期：2026-10-03

本阶段接续 `702daf2` 的账号与论坛后端检查点，仅修改 Web 论坛的接口、教师/学生组件、局部状态工具、默认头像和对应测试。

## 修复内容

- 移除请求失败时的模拟数据回退和伪造成功；保留真实错误及未确认提交提示
- 发帖、回复仅提交内容字段；操作按钮依据服务端权限，昵称和本地角色不能授予管理权
- 历史来源未核验内容不再显示为已核验教师或官方 AI 回复；头像只接受受限的本地后端路径，并提供不循环重试的本地默认图
- 补齐真实点赞、浏览和上下文接口，保留点赞的实际递增语义，不模拟撤销或幂等结果
- 隔离账号、草稿、选择和请求生命周期，防止旧响应修改新账号页面、清空新输入或覆盖新的选择
- 刷新先看见已提交内容时，延迟的提交响应按服务端 ID 对齐，不再重复插入，也不覆盖较新的读取结果
- 回复提交后往返切换帖子，正确清理原来的已发送草稿，同时保留真正的新编辑
- 分别校验完整新建对象、紧凑未回答问题、历史对象计数和公告发布响应，避免误拒绝合法旧数据或接受残缺成功响应
- 已知管理权限撤销后，审核完成不会再发起私有日志读取；服务端鉴权仍是最终权限边界
- 保留现有论坛布局，区分加载、空数据、失败、无权限和未保存输入，移除不受事实支持的在线状态及扣分成功提示
