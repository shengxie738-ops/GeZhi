# GeZhi B2 签名 HTTP 接口进展

本阶段已接入作业草稿、冻结版本、发布预览与确认、学习者提交及历史查询的严格 HTTP 适配器，并完成限定范围的源码与合成数据验证。教师与学习者的端到端 API 流程已在隔离测试进程中验证，生产写入仍保持关闭。

## 已接入的流程与边界

- 作业公开草稿保存、单独授权的私有内容保存、不可变版本冻结、仅含公开内容的发布预览、完整接收者分页与绑定确认
- 学习者读取已发布内容、提交静态文本或代码、查询本人当前提交头和按序号排列的历史；旧父提交会发生冲突，后续提交保留原记录
- 教师按当前权限与可信学习者范围查询提交。当前学习者资格失效后，本人访问与回执恢复被拒绝，历史发布接收者记录仍保留
- 全部七种有限写入动作复用原回执恢复接口。同一请求重试返回原回执，较新草稿、提交头或课程状态不会把原接受结果替换为当前状态；恢复仍重新检查当前权限
- 使用真实签名解码与持久化合成账户的当前身份解析。令牌中的旧角色声明不能替代当前账户角色、课程权限或发布接收者资格
- 详情与写入接口拒绝查询参数，列表严格拒绝未知、重复与无效字段。既有九种游标格式及账户、对象、筛选和位置绑定保持不变；游标不授予访问权限
- 学习者响应与接受回执不含私有答案、私有摘要或完整受众快照。异常处理仅记录关联 ID 和异常类别，不记录异常正文、堆栈、用户创作内容或 SQL 语句及参数

共享的身份、专用数据库会话、响应封装及提交后才返回成功的逻辑继续复用。接口新增在独立模块中，汇总路由只做结构性挂载。

## 读取准备状态与写入关闭

B2 的 configured、installed、available 仅描述读取准备状态。installed 必须对应实际匹配的物理结构及组件完成记录；available 还要求 B1 读取前提、作业开关和既有数据库结构与供应商检查均满足。模块能导入不代表组件已安装，SQLite 结果仍属于合成验证。

每个阶段和总能力响应均明确标注 writes_available=false、write_reason=write_safety_unproven。公开可用写入动作仍为空，生产安全门保持原样，无条件返回 503 write_safety_unproven；四个教学开关的默认值未改变。

B3 反馈和 B4 修改机会保持不可用。提交内容作为静态数据保存，语言标签不启用代码执行；响应明确标注 execution_status=not_available、assessment_status=not_implemented。接受提交不表示完成评测、评分或提升掌握程度。
