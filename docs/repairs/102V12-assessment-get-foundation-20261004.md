# Read-only assessment GET foundation

Adds ten finite primary B2 GET adapters and strict detached response validators for assignment/version/release and own/scoped submission reads. Private specifications, release previews, recipient lists, recovery and all write routes remain excluded.

The transport preserves token/abort fencing and sanitized errors, snapshots caller signal and selector values, validates separate bounded B2 cursors and exact teacher subjects, and suppresses reflected correlation values from all decoded object/query slots. B1 and legacy transport behavior remain covered by scoped regression tests.

Final frozen synthetic verification passed 183 cases across nine explicitly selected modules, with no failures/skips/cancellations. Tests-first failures included missing route registration, mutable selector/signal races, contradictory null history heads, and non-IANA timezone acceptance. Independent source/evidence review accepted the seven-file boundary.

Timezone validation intentionally covers the documented browser-supported subset, retaining wire spelling and tested UTC/GMT and common aliases. Other legitimate backend ZoneInfo aliases may report unavailable; complete timezone database equivalence is not claimed.

This checkpoint does not mount B2 pages. Future resource owners must still bind actor, mode, permissions, projection, full query, generations and accumulated-page ancestry. It is not native browser, backend, database or production-write acceptance. Existing write safety remains closed; no main merge or deployment is included.
