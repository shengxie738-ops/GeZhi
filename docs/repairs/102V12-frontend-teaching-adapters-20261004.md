# GeZhi 教学读取与回执恢复前端基础层

本阶段已完成 B1 教学读取与原回执恢复的前端 API 适配层，并通过限定的源码与合成数据验证。现有非教学请求行为保持原样，教学写入继续关闭。

## 已完成的基础能力

- 提供能力查询、本人可见课程与课程班列表和详情、本人选课关系，以及名单、角色读取。每次请求仍由服务端检查当前身份与权限
- 原回执可按原动作、范围和回执键查询，也可按回执编号恢复。恢复查询保留原始定位信息，不创建新请求或打开新写入权限
- 只允许已登记的 B1 GET 路径和查询字段。标识只编码一次；外部地址、路径越界、重复参数及自定义请求头、正文、写方法、流式或二进制选项会被拒绝
- 成功读取必须同时满足 HTTP 200 和响应封套 code 200，并通过严格的数据类型、字段、可空值和枚举校验。整数超出 JavaScript 安全范围时拒绝使用；中文与其他 Unicode 文本按字符计数，描述中的 CRLF 和换行保持原样
- 功能关闭、读取失败、内容不可见与空列表分别处理，不用空列表、零值或成功状态掩盖缺失的数据
- 教学请求使用专用安全错误处理。错误信息与日志不包含原始请求地址、查询参数、回执键、令牌、响应正文或异常原因；只保留经过校验的状态、机器原因及可选关联标识
- 保留令牌变化、取消请求和迟到响应的隔离检查，以及当前会话的登录失效事件行为。补充修复身份存储不可用时的错误回退，以及回执键被错误回显为关联标识的问题
- 写入门禁始终返回 mutationAllowed=false。教师身份、配置权限、伪造的写入能力或可用动作列表均不能开启新写入

## 分别记录的验证结果

以下四个限定范围在最终固定源码上分别执行并通过：

- B1 API 契约：27/27
- 可用性与写入门禁：8/8
- 既有 API 行为回归：9/9
- 登录状态切换回归：3/3

各范围均无失败、取消、跳过或待办项。新增行为先确认测试失败，再验证实现通过；两个安全错误回归也分别确认失败原因和修复后的完整断言。这些范围不累加为总覆盖数。

## 当前边界与未完成验证

本次交付的是前端读取与恢复基础适配层，尚未增加教学工作台界面、组件挂载或菜单入口，也未接入 B2 作业、发布、提交或任何写操作。

验证范围为离线源码与合成数据。真实浏览器交互、线上 API 联调、真实 MySQL、数据库迁移及生产写入安全验证尚未执行；完整测试套件与生产环境尚未验收。现有默认关闭状态、后端安全门和上线前提保持不变。
