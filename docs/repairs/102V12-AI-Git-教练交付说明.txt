运行边界与取舍
- 当前规则检查协作规范，不代表算法正确性、安全审计、CI 通过或学生真实学习能力评分。
- 账号绑定只证明映射关系，不是未经签名 Git 提交的密码学作者证明。
- 单次 diff 证据预算为 3500 字符；截断会标记 incomplete。每个任务最多 20 项执行 diff/模型分析，超出项保留规则结果并标记预算不足，不凭空得出完整 AI 结论。
- 默认每任务最多三次尝试；手动重试不能清零次数。工作线程有租约/心跳和软时间预算，不能强制中止 Python 同步线程；部署仍需要进程监督和告警。
- 持久化入队/结果具有幂等保护，但外部模型执行是至少一次语义：若模型已返回、结果尚未提交时进程崩溃，重试可能再次调用模型并产生费用。不能承诺外部计费恰好一次。
- 事件/提交账本默认不自动清理，以保留重放保护；生产环境需监控数据库容量，并谨慎制定保留策略。
- 历史点评没有可信原始事件，不会伪造可重试任务。新任务重试保留该任务当前点评，不承诺每次尝试的完整永久文本版本。
