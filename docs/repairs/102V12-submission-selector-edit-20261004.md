# Consecutive teacher subject filtering

Preserves the exact locally typed subject while synchronously clearing the prior student's installed history/detail/cursors. Stable watched sources avoid a false-to-false computed transition resetting the input in the application's Vue 3.3.4 runtime. A read-only authority identity still clears unsubmitted drafts on real actor/context changes; returning to submitted-head mode explicitly clears the draft.

The exact Vue 3.3.4 bundle was pinned as an immutable test companion. Tests-first evidence reproduced 11 failures; the final 13 selector cases passed, alongside all 308 unchanged companion cases. The existing Vue 3.5.39 harness alone did not reproduce the original computed-stability behavior and is not substituted for that evidence.

Independent source/evidence review accepted the three-file patch and finite test-only resolver mapping; production vendor, launcher and guards were unchanged. Actual desktop browser retesting remains separate. No API/authority expansion, business write activation, main merge or deployment is included.
