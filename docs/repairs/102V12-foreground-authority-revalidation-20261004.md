# Teaching foreground authority revalidation

On a genuine return to the active teaching workspace, recheck the current account and reload authority before restoring protected read data. Hidden teaching state clears and aborts old resource requests immediately without background polling. Ordinary blur only arms a return; focus/visibility events share one in-flight operation.

The teaching shell remains mounted in a blocked checking/retry state. Legacy views and active exams are excluded from this new lifecycle, with no added leave/save/flush call. A different actor cannot inherit the previous selection. A revoked previous mode requires a new explicit choice; transient enrollment/network errors remain safely blocked and retryable rather than being mistaken for authority loss.

Restoration uses fresh capabilities, offering/enrollment and first-page B2 ancestry. It does not restore old teacher subject filters, cursors, private data, write intent or cached permissions, and it does not move focus or scroll. New navigation, token/actor changes, hidden departure and disposal defeat stale restoration.

The corrected frozen candidate passed 328 Node cases across the selected scopes plus the unchanged static exam-security module. The foreground suite and selector companion use the actual repository Vue 3.3.4 bundle; other existing companions retain their pinned runtime. Independent source/evidence review accepted the six-file candidate. Actual desktop focus/visibility behavior still requires browser QA. No business-write activation, main merge or deployment is included.
