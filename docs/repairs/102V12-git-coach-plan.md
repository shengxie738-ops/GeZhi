## 验收约束
测试使用合成数据、网络拦截与模拟 Gitea/模型。不得使用提供的真实凭据、调用付费服务、修改恢复数据库基线、推送远程仓库或部署公网。RAGFlow 不在此次范围。

模型 SDK 超时、应用级重试和任务租约应分别定义，不能将线程等待超时宣称为强制中止远程请求。持久化任务必须有实际运行与恢复路径，不能只新增表。旧反馈须有保留或迁移策略；数据库变更应为可审阅、幂等的增量方案，仅在独立测试数据库验证。

浏览器本地预览当前受扩展拦截，不将源码／Node 测试宣称为真实页面点击验收。真实 Gitea webhook 与实际 AI 质量／计费行为需另行授权联调。
