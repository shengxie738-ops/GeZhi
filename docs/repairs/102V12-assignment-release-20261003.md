# GeZhi B2 Task4：完整受众预览与不可变发布

本阶段已完成源代码实现与隔离环境验证。生产写入安全门仍保持关闭，尚未接入 HTTP 接口或用户界面，不代表功能已上线。

## 本次实现

- 支持明确选择最多 1,000 名学员，保存完整受众快照，并提供全名单分页。首屏展示 100 人，剩余名单可继续翻页，完整人数和摘要不会用抽样结果代替
- 发布预览有效期为 15 分钟。截止时间仅接受严格 UTC 格式；新预览和新发布确认要求截止时间严格晚于最终校验时刻。预览同时保存开课时区，发布后的显示沿用该不可变时区快照
- 发布确认绑定预览、作业固定版本、公开内容摘要、完整受众人数与摘要、截止政策，并重新检查当前权限、名单及相关版本。确认后创建固定发布记录、完整收件人集合，以及每名收件人的空提交头
- 同一固定版本只能发布一次。后续新增学员不会自动进入历史受众；撤回学员当前访问权不会删除原有历史收件人记录
- 已接受请求可恢复原始回执。预览过期、截止时间经过或历史收件人账户变化不会将原请求误当成新请求；操作者仍必须具备当前对应权限
- 学员看到的发布内容不含其他收件人信息、受众人数或私有答案。教师管理视图中的完整快照人数，与历史收件人分页中的当前可见人数明确区分；历史分页仅列出当前授权范围内的记录和人数
- 新增三类严格绑定操作者与对象的分页游标：发布列表、预览收件人、历史收件人。游标只表示分页位置，不授予访问权限

## 验证边界

- 实际 MySQL 的账户别名与排序规则、迁移、锁竞争与等待、提交结果不确定性、真实事务原子性仍未验证

- HTTP 接口、用户界面及真实浏览器流程尚未接入；提交、评分、代码运行与通知不属于本阶段
