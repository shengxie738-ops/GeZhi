# Explicit read-detail focus handoff

After an explicit successful assignment/version/release or submission-detail action, focus moves to the current installed heading and only the owned content pane scrolls enough to make it visible. Stale, denied, failed, unmounted, initial-locator, background-refresh and pagination responses do not move focus. Deliberate user focus changes while a read is pending are respected.

The exact seven-file patch passed 308 scoped guarded cases across 13 modules, including 21 focus cases. A tests-first replay reached 11 expected failures with ten existing negative controls passing. Independent source/evidence review found no blocking source issue. Authority owners, routing, main integration and API contracts were unchanged.

These tests use Vue/compiler-dom 3.5.39 with synthetic host geometry. Actual bundled Vue 3.3.4 browser focus, scrolling and pixels require separate desktop retesting. No mobile work, business-write activation, main merge or deployment is included.
