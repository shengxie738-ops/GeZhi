## Execution boundary

`backend/tests/run_work_byok_offline.py` admits only manifest-reviewed test files and simple pytest node selectors. It launches the same verified existing interpreter with `-I`, temporary CWD/HOME, a synthetic-only environment, disabled plugin autoload, no project conftest discovery above tests, no cache/bytecode writes to sources. Test imports of `app` must resolve under this export, and exact app modules require manifest registration. Audit hooks deny sockets/DNS, unregistered SDK imports, subprocess/native-library loads, forbidden `.env`/Git/secrets/session reads and writes outside the temporary CWD. The hooks are accidental-I/O tripwires for reviewed code, not a hostile-code sandbox.

Only explicitly supplied synthetic recording ports are usable in the initial scenario. They do not construct clients, decrypt, query DBs or read settings. Expected denial assertions are counted separately; any unanticipated denied I/O makes the run fail even when a test catches its exception. HTTPX live attempts are denied before a socket or hostname resolution can occur. No existing all-repository suite is registered here.
