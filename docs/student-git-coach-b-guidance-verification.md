## 指导与证据边界

- 保留 clone、branch、commit、push、pull_request、merge 六个原有标识，新增 review、post_merge、conflict。每张卡片分别显示说明、状态来源、操作前提、命令条件和下一步提示
- 后端纯指导构建器复用既有分支校验规则，读取当前任务投影。前端回执校验稳定成员身份、任务版本、仓库身份与指导包的一致性；不匹配或旧式回执使用保守指导
- 当前查看者只使用自己的规范成员身份和任务分支。非成员、冲突的旧 ID 别名、缺少分支或未验证任务分配不会借用队长的仓库分支
- “本人确认已拉取”仅来自对应成员和仓库的学生确认，不表示系统检查过本机。远端提交、刷新成功和 PR 存在不能证明本机 clone 或可靠 push 投递
- 同一任务分支上已观察到、但任务归属未确认的提交保留中性说明。该说明不建立任务绑定，不增加已 push 或已合并计数，也不制造命令执行证据
- 当前任务远端 PR 合并、流程进度和待审数量使用明确的当前任务标签；提交与贡献计数注明累计范围。远端流程完成不表示代码正确、测试通过、原生审核通过、学生掌握程度或本机同步完成

## 操作提示

- 分支、push、PR 和合并后同步使用成员任务分支与配置的默认分支；任务分支不能与默认分支相同；PR 的目标分支仍为配置的默认分支
- 复制控件按单条命令展示并校验。选择文件和提交说明保留为不可直接复制的模板；空命令、网页地址、危险命令或未列入卡片的命令不能通过复制校验
- 先提示检查工作区、当前分支、未提交改动及进行中的 merge/rebase。合并后同步要求成功切换到同一配置默认分支，再执行 fast-forward-only 更新；不提供默认 force push、reset、删除分支、全量暂存或隐式 rebase
- 手动 PR 链接与终端命令分开。链接必须匹配回执中的仓库身份及精确 head/base；push 投递证据未知时仍可由本人核对实际推送和本机状态后手动创建 PR
- 原生审核、CI、本机测试及合并后同步分别保持未知。学习系统初审和工作流得分不能替代这些证据
- 冲突提示默认是条件指导。限定测试包含精确匹配当前 PR head 的合成冲突证据，以及旧 head 和身份不匹配的拒绝案例；当前没有生产适配器供应这一新增可选冲突证据，未证明真实冲突检测
